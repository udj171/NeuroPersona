# NeuroPersona
Enhanced Framework for personality assessment

A scientific personality assessment platform with deception correction, ML-powered classification, and AI-generated insights.

## Features
- 35-item personality questionnaire (0-10 Likert scale)
- Deception susceptibility detection (Λ parameter)
- Domain-specific bias correction (Δ framework)
- Deep learning VAE classification
- AI-powered narrative generation (Gemini/ChatGPT)
- Beautiful results visualization with charts
- PDF export functionality

### Prerequisites
- Python 3.9+
- PostgreSQL
- Node.js (optional, for frontend development)
